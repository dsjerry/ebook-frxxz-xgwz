# 第四章 示弱

称天的秤，还没造出来之前，先干最要紧的活——

请君。

殿内第十日，青年的小队，穿到了第六重殿域的边缘——"碑廊"。

碑廊是虚天殿里第二处"静地"：一条百丈的长廊，两壁嵌满了上古的碑刻，碑上的文字，万年的岁月磨去了大半，只余零星几处，还闪着微光。殿内的修士，多在碑廊驻足——有人拓碑，有人参悟，也有人，只是借这条廊，避开外面的乱。

青年独自一人在碑廊的深处，拓一方残碑。

他的小队散在廊外休整——他给自己的理由是"拓碑不宜人扰"，给小队的理由是"此碑与我功法有缘"。

两个理由，都真。

两个理由，也都是把"独处"安排得顺理成章的，壳。

萧诧等的就是这个独处。

碑廊的深处，残碑的第十七方——那一方碑，与其他的碑，不一样。其他的碑是"刻"的，那一方碑是"封"的：碑面之下，封着两千年前的萧诧，提前……不。

不是提前。

是殿开之前的那两千年里，殿基夹层中的他，顺着一道殿身的暗纹，将一缕分魂养在了这方碑里——两千年暗养，这缕分魂，如今在碑中，凝出了一副"形"：

一个上古修士的残念。

油尽灯枯，形销魄弱，一缕将散未散的魂火，在碑面之下，明明灭灭。

殿内第十日的黄昏，青年拓碑的手，忽然，停了。

他的神识，触到了碑面之下的那缕"魂火"。

他缓缓收了拓纸，退后半步，目光落在残碑上，不瞬——那只搭在储物袋上的手，指节松着，随时能起。

沉默对峙了一炷香。

而后，碑中的"残念"，"醒"了。

一缕苍老的、微弱的意识，从碑面下缓缓浮起，浮起的形态，控制得恰到好处——不是现身，是"被看见"：像一盏将熄的灯，被人隔窗，望见了。

"……修士。"

残念的"声音"，断续，沙哑，带着万年老朽特有的那种，气若游丝：

"老朽……虚天殿，守碑之人……"

"万年……困于此碑……只余，一缕……"

"修士……莫惊。老朽这缕残念……撑不过，百日了……"

碑外，青年不语。

他的神识，把那缕残念，从上到下，扫了三遍。

扫完，他开口了。声音很平，问的却是题外话：

"前辈既是守碑人——这碑廊百丈，为何独独，这一方碑，封着魂？"

好问题。

问的不是"你是谁"，是"你为什么在这儿"——问来历的，是猎物；问处境的，是猎人。

碑中，萧诧的分魂，苍老地，"咳"了一声。

"因为……老朽，当年，犯了错。"

"殿主……归天之前，封殿清修之地……老朽贪看……殿中至宝……被罚，守碑，魂不入轮回……"

"修士……老朽不求别的……"

"老朽在这碑里，万年了……只求……一件……"

"求修士……行个方便……将来……若能出殿……替老朽……在殿外的海边……烧一炷香……"

"香不用好香……老朽……只求……有人记得……这里……困过一个……人……"

碑外，青年的目光，在那缕魂火上，停了很久。

很久之后，他问出了第二句话。

这一句话，让殿基夹层里两千岁的本体，都为之，指尖一动——

"前辈。"青年缓缓地问，"你困了一万年——"

"怎么还没疯？"

这一问，问得极冷。

冷得像一把刀，隔着碑面，架在了这缕"残念"的魂火上——疯不疯，是一个万年老魂的破绽：装的，答不出真味；真的，答不出条理。

碑中，萧诧的分魂，静了三息。

三息之后，"残念"发出一声极轻的、自嘲的笑。

"……修士问的，是老朽……这一万年……怎么熬的。"

"熬……就是熬。"

"前五百年，老朽日日咒骂——骂殿主，骂天，骂自己那双……贪的手。骂到第五百年……老朽发现，骂，没用。"

"后五百年，老朽开始数……数这碑廊的纹，数殿身的呼吸，数水滴……从廊顶落下来的，每一滴。数到后来……老朽发现，数着数着，一天，就过去了。"

"再后来……老朽不数了。"

"老朽开始……等。"

"等什么，老朽自己……也不知道。等得久了……就成了……习惯。"

"修士……老朽不瞒你——老朽这缕魂……大约，是已经，疯了半分的。"

"剩下那半分……撑着的，就是这炷……还没烧上的香。"

碑外，青年静静地听完。

听完，他的目光，从那缕魂火上，收了回来。

他沉默了很久——而后，他做了一件让碑中魂、碑外魂，都微微一怔的事：

他重新铺开了拓纸。

"前辈。"他一边研墨，一边淡淡地说，"香，我会烧。"

"但不是'将来'——是这方碑，我记下了。"

"至于出去……"他顿了顿，"我自己，还没把握。"

"前辈若知道出殿的路——说说看。说得有用，拓碑之后，我在碑前，给前辈，上一炷现成的。"

碑中，"残念"苍老地，笑了。

而殿基夹层的最深处，两千岁的本体，在黑暗里，缓缓地，阖上了魂目。

他听见了。

听见这个青年，把"我会烧香"四个字，说在了"我有把握"之前。

——这一世，他扮过杂役，扮过散修，扮过岛主，扮过老鬼。

扮"残念"，这是头一遭。

也是头一遭，扮着扮着，忘了自己是扮的。

那三息的静默里，碑中的分魂说的"等"——数着水滴的等，骂完了天之后的等，不知道等什么、等成了习惯的等——

没有一句，是编的。
