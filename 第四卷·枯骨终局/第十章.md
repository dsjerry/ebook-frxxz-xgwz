# 第十章 破绽

"找个安全的地方"——这句话，是"请君"之局，最后的一钩。

青年真的找了。

傀儡渊深处，一处塌了半边的古殿密室——三面残壁，一个死角，只留一个入口。他在入口布了两道示警阵，在死角里坐下，验伤，调息，处理左臂的裂创。

密室的暗处——残壁夹层的阴影里，那缕"苍老的残魂"，无声无息地，伏着。

伏着的老魂，没有立刻动。

他在等，等这个青年，进入此行最脆弱的一刻。

修士最脆弱的一刻，不是重伤——是治伤。

疗伤之时，神识内敛，护体松弛，识海的门户，会为周天运转的灵力，开上一线。

那一线，就是两千五百年等来的——门。

一个时辰，两个时辰——

第三个小时，青年的疗伤，到了"换气"的关口：旧力将尽，新力未生，识海那一"线"，开到了最宽。

暗处的老魂，动了。

动之前，他做了最后一件事——最后一秤。

称天。

两千五百年前，狱底账壁，他刻过"天不与，则自取之"；殿内第八日，他在"请君"账上添过一笔"夺舍之局，添最后一秤，称天"。

如今，秤在心头，钩在手上，门在眼前——

这一秤，怎么称？

老魂在阴影里，只问了自己一个问题：

"这具躯，困的是龙。"

"龙困于此，是天没看见它——还是天，把它放在这儿，等我？"

问题落下的同一瞬，他自己，笑了。

笑这一问的，多余。

两千五百年前，枯壳岛的杂役房里，那个少年若也这样问一句"天没看见我，还是天在等我"——他就不会在那一夜，去碰那枚玉简。

天问不得。

问了，就不是萧诧了。

天不与——

自取之。

秤，落了。

门，开了——

老魂化作一线灰芒，顺着识海敞开的那一线，无声无息地，钻了，进去。

入海的一瞬，萧诧看见了那片"海"。

青年的识海。

不是海。

是一座——深渊。

深不见底的墨色，无边无际地铺开去；渊面平静得没有一丝波纹；渊底的最深处，沉着一轮——不是神魂，不是识念，是一轮青蒙蒙的、剑形的光。

三千柄剑，聚成的光。

剑光之下，渊壁的四面八方，凿着一层又一层的"洞府"——每一层洞府里，都盘着一道警惕的神识分身：有的执剑，有的执幡，有的抱臂，有的佝偻——层层叠叠，密如蜂巢。

三千剑，万个他。

这不是识海。

这是一座——为"不速之客"，准备了两百年的，要塞。

而更深处——渊底剑光的正下方，一点微不可察的绿，安安静静地，亮着。

像一枚，沉在渊底的，眼睛。

萧诧的一线灰芒，悬在渊面之上，那一瞬，两千五百年的老魂，遍体生寒。

进来的时机，是他此生算得最准的一次。

进来之后他才知道——

这个青年疗伤时敞开的那"一线"，不是破绽。

是门。

是他此生第一次，被人反着，请进来的——

门。

第四卷 第十章 完
