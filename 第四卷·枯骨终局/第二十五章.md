# 第二十五章 全书终 雨

枯壳岛，又一个春天。

夜里，落雨。

石屋的破窗，早就换了新窗棂——当年那个攥着旧物睡觉的少年，如今也老了，出海的活干不动了，在岛上娶妻，生子，打鱼，盖了新屋。

旧石屋没拆——他家的小儿子，眼下住在里头。

小儿子十二岁，白日里疯，夜里睡得沉。

这一夜，他被雨声，吵醒了一次。

迷迷糊糊地，他听了一会儿雨——听着听着，不知怎么，忽然想起白日里，在荒坡上遇到的一件事：

有个过路的老乞丐，在荒坡上歇脚，跟他讨了半碗水。老乞丐喝完水，看着那片荒坡，看了很久，问他：

"娃，这坡上，以前，是不是种过药？"

他说不知道。

老乞丐也没再说，只是走的时候，摸了摸他的头，笑了一声，说了一句他听不懂的话：

"好地方。"

"出过，了不起的人。"

雨声里，小儿子翻了个身，把这句没头没尾的话，又想了一遍，想不出个所以然——

也就不想了。

他打了个哈欠，闭上眼。

睡之前，他心里，模模糊糊地，过了明天的事——跟爹出海，收网，回来，把昨天没削完的那柄小木剑，削完……

削完了，他要带着木剑，去后山，找二狗他们，玩"修仙人"。

他扮那个，最厉害的。

那种一人，打一百个的。

雨，落着。

落在荒坡上，落在石屋上，落在枯壳岛千万年不变的，黑礁石上。

雨里，天地无声。

无声处——

蝼蚁，睡着了。

蝼蚁的梦里，有一柄，削了一半的，木剑。

（全书完）
