# 第十一章 蚀洞

第九百年，开工。

工，是那道蚀洞。

第九层禁制东南角，万年风化而成的裂缝——四百年前，他用"源"皮骗开老狱的眨眼，摸到了皮卷；如今，他要把这声"眨眼"，凿成一道"门"。

难，难在三点。

其一，不能快。阵纹的风化是万年尺度的事，人为加速一分，禁制的自愈就会反扑一寸。萧诧测算过：以他如今的魂力，凿洞的节奏，必须控制在禁制"察觉不到"的阈值之下——慢到什么程度？慢到一百年，只能推进一尺。

其二，不能露。凿洞的每一缕魂力，都必须裹着"源"皮——让他的一切动作，在老狱的感知里，都像风化本身。他是这座狱认定的"经种"，是"源"的一部分——一部分风化另一部分，狱，不问。

其三，最麻烦——凿开的洞，要"装"回去。

洞是门。门白天开着，就是给禁制递刀。他要在洞口布一层"伪壁"——魂力织的、外观与阵纹一般无二的假壁——平日里封着洞，只有他"出"的那一瞬，伪壁收拢。

布伪壁的术，他推演了六十年。

六十年里，他拆了自己魂脉上三分之一的"账"——那根缠了九百年的黑筋，被抽丝剥茧，织进了伪壁的经纬里。

心魔做的墙。

用它生前的疼，堵它身后的路。

第九百五十年，蚀洞推进到了九层禁制的"内皮"。

再往里一寸，就是外海的水。

那一寸，他停了。

不是凿不动——是不能凿。内皮是禁制的活肉，一破，海水的"阳"动会顺着洞口灌进来，整座九层都会惊——千年工程，毁于一寸。

他改了法子。

不凿穿——"泡软"。他以极缓的魂力，日复一日地浸润那一寸内皮，浸得它薄，浸得它脆，浸到只差一声轻响的临界——然后，停手。

留着。

留着这层一捅就破的膜，像留着一扇装好了门轴、却永不推开的门。

什么时候推？

——出狱的那一天。

出狱那一天来临时，他不需要慢慢凿。他只需要，撞。

九百五十年的蛰伏，把"出"这个字，简化成了一撞。

而撞出去之后的事，他也在这一百年里，备齐了。

备齐的东西有三样。

第一样，"潭"。蚀洞外的海底，有一处天然的凹陷，状如浅盆——他以坠狱之柴的遗骨残器，在盆底布了一个"迷魂小阵"。阵不杀人，只"引"——引路过此地的低阶修士，恍惚间，看见盆底有宝光。见与不见，来与不来，随缘。

这是钩。

第二样，"衣"。玄魂体出狱，不能以魂形见人——鬼道残魂，天地不容。他以九百年攒下的魂力，炼了一件"皮"——魂力凝成的、约莫人形的、罩在玄魂外的一层假壳。壳成之日，他照着记忆里的模样，捏了一张脸。

不是萧诧的脸。

是个无名散修的脸——眉目平庸，气质平平，扔进人堆里，三息就忘的那种。

第三样，最简单，也最难——

"名"。

他给自己，起了一个新名字。

想了三十年。

最后定下的那一个，只有两个字。既不高雅，也无深意——普通得就像他捏的那张脸：

"玄骨"二字，是不能用了。

"萧诧"二字，不敢用了。

他最后选的，是当年碎星海原一战之后，散修们私下叫他的那个诨号——不是"玄骨上人"，是更早的、更野的、他做独行客时的名号：

黑骨。

九百五十年，夜——自定的夜——账壁添行：

"工成。洞成。潭成。衣成。名成。"

"黑骨，候时。"
