# 第一章 灰烬之下

黑暗里，没有时间。

萧诧残婴坠入古修禁制的最初岁月，是数不出来的。一天和一年没有分别，醒与睡没有分别——不足一成的婴体，缩在禁制夹缝的一处死角里，像一粒被海泥裹住的火星，微弱地，明灭着。

他做的第一件事，是活。

不是想活。是"活"本身——残婴的本能。修士的元婴是元神与法力的结晶，只要不散，就会本能地维系自身。这门本能不问意志：哪怕他此刻万念俱灰，残婴也在一丝一丝地，从周围的禁制乱流里，攫取着微不可查的阴属之气，续着自己。

像一具断了脊梁的兽，趴在血泊里，心口还在跳。

跳一下，是一下。

不知过了多久——三个月，或者三年——那点本能的攫取，终于攒够了重启神识的力气。

萧诧"醒"了。

醒来的第一个知觉，是疼。

不是肉身的疼——肉身早就散在崖顶的夜风里了。是元神的疼。化神清光被生生撕走一角的伤，还留在元神的底子上：那里空了一块，空得像一口被连根拔了牙的牙床，风一吹，就疼。

疼完了，是冷。

禁制夹缝的深处，没有光，没有声，没有上下。古修禁制的力量如水如壁，从四面八方缓缓地压着——那不是杀意，是"关"：关住一切试图进出的东西，包括他这缕残婴。

冷完了，才是想。

萧诧在黑暗里，用他此生最慢的速度，把那一夜，从头到尾，想了一遍。

崖顶的灯。翻转的阵。极阴的三条理由。极炫收着三寸的刀。骨幡、锁阵、万流压落——以及自己最后那一笑。

想完，他在黑暗里静了很久。

然后他想的是另外一些事：碑林那块总纲碑，碑座下封着的那封信；库藏堂深处，封存的第三钥；岁祭之夜，礁岩上的酒渍；还有五十七年前，传法殿上，那个十六岁的少年，跪在他面前，答"证明不了，便依师尊的道走"。

一桩，一件，一寸，一分。

他把这一夜之前的一切，也从头到尾，想了一遍。

想到枯壳岛的药圃，想到沈老魔的玉简，想到幽冥海沟第一次碎丹，想到碎星海原的矛雨，想到沉珠群岛的万家灯火——

想到望海崖上，那个清晨，他逆着光说：十年之后，无论为师在不在，玄阴岛都要在。

在。

还在。

他不知道那个"在"，如今是什么模样。残婴缩在禁制夹缝里，神识探出去不到十丈，十丈之外，是海沟，是海，是他再也看不见的人间。

萧诠在黑暗里，做了他"死后"的第一个决断。

不想了。

过去的一切——岛、碑、弟子、名、五百年——尽数封存。不是忘。是"不想"。想了，神识就散；神识散了，这缕残婴就真的死了。

而他还不想死。

不是不甘，不是怨恨，不是放不下——这些，都有。但在这些之下，还有一样更老的东西。五百年前它就在了，五百年后，它还在：

那口气。

不想做蝼蚁。

——做过了人上人，如今又做回了蝼蚁。那就再爬一次。

萧诧收敛神识，把残婴缩得更小，小到禁制乱流都懒得挤压的一粒。

然后，他开始做第二件事。

探。

探这座囚笼。

探，是比活更慢的一件事。

残婴的神识只有十丈。十丈，放在五百年前，不够他一次骨遁的距离；放在如今，是他全部的疆土。

他就用这十丈，像一只蚂蚁丈量一座山那样，一寸一寸地，摸这座禁制。

第一个一百年里——他后来是这样计年的：以残婴每一次从沉寂到苏醒为一年——他摸清了夹缝的形状。

那不是一道缝，是一层"壳"里的缝。古修禁制如一枚巨大的茧，将他坠落的那片海沟最深处，整个包裹了进去。茧有九层，层与层之间，是乱流与死寂交替的夹缝。他此刻蜷缩的地方，是第九层的最底部。

第二个一百年，他摸清了禁制的"性"。

这九层禁制，不是乱布的。萧诧越摸，心越沉——那是一个阵。一个完整的、活的、上古的阵。阵的目的不是杀，是"囚"；阵的力量不来自灵石，而来自地底——幽冥海沟最深处的地煞之眼，是这个阵万古不枯的心。

以地煞为心，以海沟为壳。

这座囚笼，比玄阴岛任何一座大阵都要古老，都要完整。

是誰修的？为什么修在这里？修来关什么？

第三个一百年，他找到了第一个答案。

那年——他计年的第三百年前后——他在第九层禁制的底部，摸到了一样东西。

不是乱流，不是死寂，不是阵纹。

是一块碑。

一块沉在禁制最底、被万古地煞之气包裹着的残碑。碑不大，断成了三截，字迹漫漶——萧诧用残婴贴着碑面，一个字一个字地，读。

读了整整十年。

碑上刻的不是祭文，是一篇"封谷志"——修碑者自述，他奉门中之令，于此地煞之眼之上，筑九层镇狱大阵，封镇"本门之祸"。

落款处，刻着门号。

两个字，磨得只剩浅浅的沟痕，但萧诧不需要看全——那两个字他太熟了。他亲手把这两个字刻上三百六十块碑，亲手把这两个字，传给了十万人。

玄阴。

这座囚笼，是玄阴一脉的祖辈，修的。

镇的不是外敌。碑志的末句写着："祸起于经，镇于经源。经在，狱在；经绝，狱开。"

萧诧的残婴，在黑暗里，贴着那块断碑，停了很久很久。

原来幽冥海沟——他五百年前结婴的这条海沟，他闭关冲击化神的地方——是玄阴一脉的上古祖地。地煞之眼上的九层大阵，是祖辈镇"祸"的狱。他的骨渊残婴坠下来，是坠进了自家祖坟的棺材底。

而极阴，那夜立在崖沿，袖手看着这缕残婴坠落，说"它会自己走进去的"——

那个婴中带着"源"的弟子，早就知道这里是什么地方。

黑暗无边。

残婴极轻地，离开了断碑，继续向禁制的更深处，摸去。

这一次，它摸向的方向，是碑志末句里的那三个字——

"经源"所在。
