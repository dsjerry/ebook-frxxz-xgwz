# 第二十七章 岁祭

新巢的岁月，是从"数客"开始的。

第一百年，三客。

第三百年，年均有客——荒海的名声，随着那三个散修的失踪，慢慢在亡命徒的圈子里，传开了。传的版本越来越邪：有人说沉山底下有上古大能的遗府，有人说有万年凶兽，还有人说，山底下压着一个"吃魂的老魔"。

说对的那一拨人，都成了池底的涟漪。

萧诧的日子，落进了一种新的循环——

无客的月份，修炼、观海、刻账。玄魂体的修为，随着养魂池的日积月累，缓缓地爬：结丹初期，回到了中期——那缕割给经源殿的分魂，用三百年的池力，补了回来。

有客的年份，问魂、炼化、录西壁。

每年岁末，空室上香——祭七代前辈，也祭，他自己这一年里"过路"的，那些柴。

日子久了，他发现一件事。

他开始，记得住每一缕柴的脸。

不是魂力层面记得住——是"记"。吴某要修的娘的坟，柳某老婆的那句"别去"，无名小修士"下辈子投个好胎"的愿望——一缕一缕，都进了他千年不曾波动的心湖。

换作千年前，这叫心软。

心软，是修鬼道的大忌。

可萧诧没有改。

他只是在每一缕柴入池之前，多做了一件事——把那缕柴生前最后的执念，摘出来，封进一枚小小的魂珠，投入山府外围的洋流里，随波而去。

魂珠入水，百川归海。

执念所系的那个方向——故乡的坟，老婆的窗，没投成的好胎——珠子会自己，飘过去。

飘到了，化开，那一缕未了的念，就散在了它该散的地方。

入土，为安。

这是他为柴做的，唯一一件事。

不费什么魂力，也不求什么因果——他就是觉得，烧了人家的魂，总得替人家，把最后一句话，捎到。

第五百年，岁祭，出了一件小事。

那一年的客，是个筑基后期的女修。

她闯进山府的方式，跟所有的客都不一样——不是寻宝，不是探险，是被追杀。三个结丹散修，追她一个筑基，从荒海东缘，一路追到了沉山门口。

按理，山门之外的事，萧诧不管——巢规第一条，来者不问，不来者，更不问。

可那女修被追急了，一头扎进了山府的石门——追兵跟着，也扎了进来。

一进门，就是客。

三个追兵，成了柴。

女修，也成了"客"——萧诧没有动她。

她瘫在第一重殿宇的地上，看着三个追兵在殿宇深处"失足"于幻阵、再没出来的过程，抖得像风里的草。抖完了，她朝着殿宇深处——朝着那缕"垂死残魂"的气息——磕了三个头，转身，连滚带爬地，逃出了山府。

自始至终，萧诧没有现身。

她不知道自己欠了谁，也不知道救她的是什么——她只知道，沉山底下那个"东西"，收了她的追兵，放了她一条生路。

女修走后，萧诧在刻账室，想了很久。

西壁上，他破例，为这一位"没烧的客"，也刻了三行：

"客，某女修，筑基后期，来历不明。"

"生平三行：不详。"

"记之——巢，今日起，不只进柴。也……放生。"

刻完，他自己看着那三行字，看了很久。

放生。

一个吃魂的巢，立了放生的例。

这规矩，坏不坏？

他想了想，没有答案。

他只想起千年前，那个坐在潭边啃干粮的陈拙——想起他说"这潭底下住着的，是个好人"。

……那就当，是个好人开的巢吧。
