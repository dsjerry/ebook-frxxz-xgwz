# 第十七章 盛世裂

第一千一百六十年，外间，裂了第一道缝。

消息不是陈拙带来的——是柴。

那年坠狱的柴，是两名结丹修士的残魂——玄阴岛自己的执事。他们死得很蹊跷：不是闯沟死的，是在沟口上空，被人杀了的。

杀他们的人，手法干净，魂伤而尸不伤——两名结丹中期的玄阴执事，连遁光都没来得及起，魂就碎了。

凶手杀人之后，扬长而去。两缕残魂坠进沟来，被大阵误作"闯狱者"，一路绞到第九层——绞到萧诧嘴边。

问魂问出的东西，让萧诧在黑暗里，坐了整整一夜。

两名执事生前最后一趟差事，是奉命去沟口，布置岁祭船的仪程——今年的岁祭，规格提了三成。

为什么提？

因为今岁，是"先岛主兵解"的第一千一百六十年，玄阴岛要办"千一百甲子大庆"。

大庆之外，还有一件真正的要紧事：岛主极阴，要第四次，冲化神。

执事的记忆里，关于这次冲击的只言片语，拼起来是这样一幅图景：岛主已闭关九年；护法军全线戒严；七十二岛的核心弟子，被抽调了三千，日夜在大阵上轮值"护关"——

名义是护关。

执事魂识最深处的一段私语，却被萧诧"问"了出来——那是两人在沟口布置仪程时，压得极低的一段闲话：

"……你说，这次能成么？"

"嘘——你不要命了？"

"我就是觉得……岛主这九年，老得有点快。上回我隔着禁制远远瞧见……那头发，全白了。"

"……第三次没成的时候，中枢殿里，一夜没人说话。这次要再……"

"打住。打住！干咱们的活。"

夜——自定的夜——萧诧在账壁前，把这两缕魂的信息，从头盘了一遍。

盘出三层东西。

第一层，明面：极阴第四次冲化神，九年闭关，形销骨立。

冲化神，他萧诧当年只差一步，深知这一关的斤两——元神与天地法则相融，融一分，天消一分"我"。极阴的道基，是夺来的：功法是玄阴的，阵是骨渊的，连"元婴后期"这四个字，都垫着一座吸来的灵脉。这样的道基冲化神——

天地法则融他的时候，融的是"他"，还是融的是"萧诧的经"？

若是后者——他每冲一次，都在替狱底的萧诧，把《玄阴经》往"合道"的尽头，推一分。

推到尽头，是什么，殿内那位，一千六百年前就示范过了。

第二层，暗面：杀两名执事的凶手。

手法是魂杀。乱星海里玩魂杀的，萧诧千年见闻拼图里，只有一家——

冰渊。

安静了千年的渊使，动了。

动的不是兵，不是使——是一缕"手"。在玄阴岛最要紧的关口前，掐死两名无关紧要的执事，留下一具干净得反常的现场。

这不是刺杀。

这是……敲钟。

或者，是"催"——催那座大阵上轮值的三千弟子，催那九年白发的岛主，催这场冲击，快一点，再快一点。

第三层，最深处：千一百甲子大庆。

以他的死纪年，以他的名义大庆，以他的碑，聚三千弟子的人气——聚在一场冲击的阵前。

萧诧在黑暗里，无声地笑了。

一千六百年前，崖顶那夜，极阴用他的功法、他的阵、他的信任，锁了他的婴。

一千六百年后，极阴要用他的经、他的名、他的碑——冲自己的神。

这个人，从头到尾，就没有一样东西，是自己的。

那一夜，账壁《候腐》篇下，添行：

"第一千一百六十年，录：彼第四次冲神，九年未出，发白。渊使首动，魂杀二执事于沟口。"

"梁，开始朽了。"

"推——不必急。"

"看它，自己，往哪儿倒。"

第三卷 第十七章 完
